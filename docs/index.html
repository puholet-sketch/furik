Заключение трудового договора черновик готов · подпись todo

Бессрочный договор + увольнение по собственному желанию · ИП Сорванова · Киевская 7к2.

Почему не срочный «на 3 месяца». По ч. 5 ст. 327.1 ТК РФ с иностранцем по умолчанию — договор на неопределённый срок. Срок патента сам по себе не основание срочности. Срочный возможен только по ст. 59 ТК РФ (у ИП ≤ 35 работников — по соглашению сторон). Для сценария «~3 месяца и уход» безопаснее бессрочный + заявление по ст. 80 ТК РФ.

Зарплата «на руки»

Оклад минус НДФЛ (если НДФЛ не зачтён авансами по патенту — см. ниже). Только безнал на счёт в ПАО Сбербанк из ТД.

НДФЛ 13–22%

Работодатель — налоговый агент. Для патента обычно старт 13% с базы до порога прогрессии.

Куда: ФНС через ЕНП · кабинет ИП / банк-клиент

ИФНС (ЕНП)

Страховые взносы ~30%

ОПС + ОМС + ВНиМ единым тарифом. Для временно пребывающих (не ВКС) — как за граждан РФ.

Куда: ФНС · срок ориентир до 28-го числа следующего месяца

СФР

Травматизм 0,2%

I класс профриска (ОКВЭД 56.10 основной · 56.30 подача напитков — тот же класс). Тариф по Закону № 179-ФЗ: 0,2%. Источник классификации: приказ Минтруда № 851н (ред. от 16.05.2025).

Куда: Социальный фонд России

Работник сам

Аванс по патенту ≈ 10 000 ₽/мес

Фиксированный платёж НДФЛ за патент в Москве (2026). Это не расход ИП. В пакете есть квитанция на 10 000 ₽ от 19.07.2026.

Увольнение по собственному желанию шаблон есть

Ст. 80 ТК РФ · что делает работник и что обязан сделать ИП

Шаги работника

  1. Пишет заявление об увольнении по собственному желанию (шаблон выше).
  2. Подаёт заявление работодателю (лично под отметку / заказным письмом / иным согласованным способом).
  3. По общему правилу предупреждает за 2 недели (срок считается со дня, следующего за получением заявления). По соглашению сторон можно уволить раньше.
  4. В последний день получает расчёт и документы.

Шаги ИП (работодателя)

  1. Зарегистрировать получение заявления (дата!).
  2. Издать приказ об увольнении (ст. 84.1 ТК РФ).
  3. В день увольнения: полный расчёт (зарплата, компенсация неиспользованного отпуска и т.д.), выдать трудовую / СТД‑Р, справки.
  4. Обязательно: уведомить МВД о расторжении ТД в срок ≤ 3 рабочих дня — так же, как при приёме.
  5. Отразить увольнение в кадровой и налоговой/СФР отчётности.

Риски и частые ошибки

Что чаще всего приводит к штрафам.

  • Пропуск уведомления МВД при приёме или увольнении — штрафы в Москве существенно выше. Черновик приёма готов, но подача ещё не сделана.
  • Срочный ТД «потому что патент / 3 месяца» без ст. 59 — риск переквалификации.
  • Зарплата ниже 39 730 ₽ в Москве — трудовые и налоговые претензии.
  • Выплата наличными иностранцу — запрещена; только безнал (в ТД — Сбер).
  • Неоплата патента работником → аннулирование → обязанность отстранения.
  • Должность ≠ патент — несоответствие профессии (здесь зафиксировано: бармен).
  • «Фиктивный» короткий найм без реальной работы — риски налогов и миграции.
  • Зачёт НДФЛ по патенту без уведомления ИФНС — ошибка налогового агента.
