# Инструкция: приём и увольнение иностранца (гражданин Узбекистана, патент, ИП, г. Москва)

**Для:** индивидуального предпринимателя  
**Сценарий:** работа ~3 месяца, затем увольнение по собственному желанию  
**Рекомендуемый кадровый вариант:** бессрочный трудовой договор + заявление по ст. 80 ТК РФ  
**Дата:** 2026-07-28

> Налоги и взносы кадровик передала бухгалтеру — **все суммы, КБК, сроки уплаты ЕНП и отчёты сверить с бухгалтером ИП** перед платежами.

---

## A. До приёма — собрать документы у работника

Чеклист (как у кадровика Хабаровой Ирины + уточнения):

- [ ] Паспорт + копия (страницы с фото и регистрацией / штампами)
- [ ] Миграционная карта + копия
- [ ] Патент (оригинал для сверки) + копия; проверить:
  - срок действия покрывает дату начала работы;
  - субъект — Москва (и/или МО при «двойном» патенте);
  - профессия / вид деятельности совпадает с будущей должностью
- [ ] Квитанции об оплате авансов по патенту (актуальные)
- [ ] СНИЛС
- [ ] ИНН
- [ ] Банковские реквизиты для зарплаты (счёт / карта РФ) — **обязательно**, наличные иностранцу не платить
- [ ] Трудовая книжка (при наличии) / сведения о трудовой деятельности
- [ ] Заявление о приёме на работу (по желанию / локальным правилам ИП)
- [ ] Согласие на обработку ПДн (если оформляете)

Дополнительно проверить:
- [ ] Работник понимает, что **оплата патента (~10 000 ₽/мес. в Москве в 2026)** — его обязанность
- [ ] Если патент выдан после 07.01.2024 — работник должен в течение **2 месяцев** с выдачи патента сам уведомить МВД о начале работы и приложить копию ТД

## B. Заключение трудового договора

Рекомендация: использовать  
`docs/трудовой-договор-иностранец.docx` (**бессрочный**).

Альтернатива (только если численность работников ИП **≤ 35** и стороны согласны на срочность по ст. 59 ч. 2 ТК РФ):  
`docs/трудовой-договор-срочный-иностранец.docx`.

Шаги:

1. [ ] Заполнить все поля `[В ПИСАТЬ: …]`
2. [ ] Оклад **≥ 39 730 ₽** за полный месяц (МЗП Москвы 2026; не 32 916)
3. [ ] Вписать реквизиты патента, миграционной карты, паспорт, банк
4. [ ] Подписать **два экземпляра**; один отдать работнику под роспись
5. [ ] Издать приказ о приёме (можно по унифицированной форме / своей)
6. [ ] Ознакомить с локальными актами (ПВТР, охрана труда — если есть)
7. [ ] Внести сведения в кадровый учёт / ЭТК (через отчётность в СФР — см. ниже)

## C. Уведомление МВД о заключении ТД (критичный срок)

| | |
|---|---|
| **Срок** | Не позднее **3 рабочих дней** с даты заключения ТД |
| **Куда** | Территориальный орган МВД по **месту фактической работы** в Москве |
| **Как** | Госуслуги (УКЭП ИП) **или** лично **или** заказным письмом с описью |
| **Что** | Уведомление по форме МВД + по практике часто прикладывают копию ТД (уточнить актуальные требования бланка) |

- [ ] Подготовить уведомление (актуальный бланк на дату подачи; с 01.09.2026 возможны новые формы)
- [ ] Подать и **сохранить подтверждение** (отметка / квитанция Госуслуг / почтовый чек)
- [ ] Календарь: поставить контроль на день «ТД + 3 рабочих дня»

**Штрафы за просрочку в Москве высокие** — не откладывать.

---

## D. Постановка / отчётность в СФР и кадровая отчётность

Согласовать с бухгалтером конкретный набор (зависит от ПО и статуса ИП):

- [ ] Сообщить бухгалтеру о новом сотруднике в день приёма
- [ ] Сведения о трудовой деятельности / приём — через **ЕФС-1** (подраздел о кадровых мероприятиях) в сроки, установленные для приёма (как правило, на следующий рабочий день после кадрового события — **уточнить актуальный срок**)
- [ ] При необходимости — регистрационные действия страхователя, если ранее не было наёмных работников
- [ ] Табель / учёт рабочего времени с первого дня

## E. Налоги и взносы (что платить, куда, как часто)

> Блок для сверки с **бухгалтером**. Ниже — ориентир, не платёжка.

### Что делает работодатель (ИП)
| Платёж | Ориентир | Периодичность | Куда |
|---|---|---|---|
| НДФЛ с зарплаты | шкала 13–22% | при каждой выплате / по правилам НК (уведомления / ЕНП) | ФНС (ЕНП) |
| Страховые взносы (ОПС, ОМС, ВНиМ) | единый тариф ~30% (льготы МСП — если есть) | ежемесячно | ФНС (ЕНП) |
| Взносы на травматизм | тариф по ОКВЭД ИП | ежемесячно | СФР |
| Отчётность 6-НДФЛ, РСВ, ЕФС-1 и др. | по календарю бухгалтера | квартал / месяц | ФНС / СФР |

### Зачёт авансов по патенту в НДФЛ
1. Работник пишет заявление + даёт квитанции об оплате патента.
2. ИП запрашивает в ИФНС уведомление на уменьшение НДФЛ.
3. После получения уведомления — уменьшает исчисленный НДФЛ (ст. 227.1 НК РФ).
4. Без уведомления ИФНС зачёт не делать.

### Что платит сам работник
- [ ] Фиксированный аванс по патенту (~**10 000 ₽/мес.** в Москве в 2026) — **сам работник**, не ИП

## F. Выплата зарплаты

- [ ] Только **безнал** на реквизиты из ТД
- [ ] Соблюдать даты аванса и расчёта из договора (ст. 136 ТК РФ)
- [ ] Не выдавать зарплату наличными «в конверте» / из кассы

---

## G. Через ~3 месяца — увольнение по собственному желанию

Шаблон: `docs/заявление-об-увольнении.md` (можно распечатать / перенести в DOCX).

1. [ ] Работник пишет заявление об увольнении по собственному желанию (ст. 80 ТК РФ)
2. [ ] Срок предупреждения: обычно **не менее 14 календарных дней** (можно уволить раньше по соглашению сторон — зафиксировать письменно)
3. [ ] Приказ об увольнении
4. [ ] Расчёт: зарплата, компенсация неиспользованного отпуска (если есть)
5. [ ] Выдача трудовой / СТД-Р / документов по заявлению
6. [ ] **Уведомление МВД о расторжении ТД** — снова **≤ 3 рабочих дней**
7. [ ] Отчётность в СФР о кадровом событии (увольнение) — через бухгалтера
8. [ ] Сохранить комплект: заявление, приказ, расчёт, подтверждение уведомления МВД

Если использовали **срочный** договор — он может прекратиться истечением срока (ст. 79 ТК РФ); всё равно нужно уведомить МВД о расторжении и произвести расчёт. «Увольнение по собственному» при срочном — тоже возможно досрочно.

---

## H. Краткая хронология «одного взгляда»

```text
Документы работника
    → Подписание ТД (день 0)
        → Приказ, экземпляр работнику
            → МВД: уведомление о заключении (≤ 3 раб. дня)
            → СФР/бухгалтерия: кадровая отчётность
                → Зарплата на карту + НДФЛ/взносы (по циклу)
                    → Заявление об увольнении (~через 3 мес.)
                        → Приказ, расчёт, документы
                            → МВД: уведомление о расторжении (≤ 3 раб. дня)
```
