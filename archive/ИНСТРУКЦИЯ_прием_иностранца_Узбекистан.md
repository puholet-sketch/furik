**Актуальность проверки норм:** 2026-07-28  
**Работодатель:** ИП

## 1. Чеклист документов у кандидата

Собрать копии + сверить с оригиналами:

1. **Паспорт** гражданина Узбекистана (+ нотариальный перевод, если кадровик/банк требует).
2. **Миграционная карта** — цель въезда: **работа**.
3. **Патент** на работу:
   - срок действия / оплаченный период;
   - **регион** = Москва (или тот субъект, где фактически работают);
   - **профессия/должность** совпадает с трудовой функцией в ТД.
4. **Квитанции** оплаты фиксированных авансов по патенту (подтверждение «живости» патента).
5. **Уведомление о постановке на миграционный учёт** (регистрация по месту пребывания) — актуальный срок.
6. **СНИЛС** (если нет — оформить через СФР при приёме).
7. **ИНН** (при отсутствии — получить в ФНС).
8. **Банковские реквизиты** счёта в российском банке (карта/счёт на ФИО работника).
9. **Трудовая книжка** — при наличии (или сведения о трудовой деятельности / ЭТК).
10. **Полис ДМС** (или договор на платные медуслуги) на срок работы.
11. **Медкомиссия / сертификат** — если требуется для патента / вида работ (в папке есть PDF медучреждения — использовать как часть пакета).
12. Иные документы по должности (медкнижка, справка об отсутствии судимости — только если закон требует для конкретной работы).

В проекте уже есть пакет PDF (паспорт Узбекистана, патент/МВД, миграционная карта, медосмотр, страховка, банк «Солидарность»). Файл `СНИЛС ИНН.txt` пустой — СНИЛС/ИНН взять у кандидата отдельно.

## 2. Как оформить трудовой договор

### Рекомендация для ИП

Два рабочих варианта (оба законны при правильном оформлении):

| Вариант | Когда | Плюсы / минусы |
|---------|-------|----------------|
| **А. Бессрочный** + через ~3 мес. ст. 80 или ст. 78 | Всегда | Привычен кадрам; нужно добровольное заявление / соглашение и уведомление МВД о расторжении |
| **Б. Срочный на 3–4 мес. по соглашению сторон** | ИП с численностью **≤ 35** (ст. 59 ч. 2 ТК РФ) | Чёткий срок без «увольнения по собственному»; в договоре указать именно это основание, **не** «на срок патента» |

**Важно:**

- Ч. 5 ст. 327.1 ТК РФ: срочный ТД с иностранцем — только по общим основаниям **ст. 59 ТК РФ**.
- Срок патента / «хотим на 3 месяца» **сами по себе** не основание, но **ст. 59 ч. 2** (ИП ≤35) — полноценное основание по соглашению сторон.
- Иные основания ст. 59 (временные/сезонные работы, замещение и т.п.) — если реально есть.
- Незаконная срочность → риск переквалификации в бессрочный + претензии ГИТ.
- «Увольнение по собственному» не должно быть фиктивным под давлением.

### Обязательные сведения в ТД с иностранцем (ст. 57 + ст. 327.2 ТК РФ)

- Реквизиты **патента** (номер, дата, срок, кем выдан, территория, профессия).
- Место работы — **Москва**.
- Оплата **≥ 39 730 ₽** за полный месяц при норме труда (МЗП Москвы 2026).
- Способ выплаты: **только на банковский счёт**.
- Режим труда, права/обязанности, расторжение, ПДн.

Готовый шаблон: `Трудовой_договор_иностранец_Узбекистан.docx`.

### Кадровые шаги после подписания ТД

1. Приказ о приёме.
2. Ознакомление с ПВТР, охраной труда (подписи).
3. Личная карточка / кадровый учёт.
4. **ЕФС-1** в СФР о приёме — не позднее следующего рабочего дня (уточнить актуальный срок у бухгалтера).
5. Запись в трудовую / ЭТК.

## 3. Уведомление МВД о заключении ТД

| Параметр | Правило |
|----------|---------|
| Срок | **Не позднее 3 рабочих дней** с даты заключения ТД |
| Куда | Территориальный орган МВД по месту **фактической работы** иностранца (для Москвы — подразделение по г. Москве / через Госуслуги выбирается автоматически) |
| Способы | 1) **Госуслуги** (удобнее; нужна УКЭП ИП) 2) лично 3) почта с описью |
| Форма | До 01.09.2026 — по приказу МВД от 30.07.2020 № 536 (актуальная ред.); с 01.09.2026 — новые формы (приказ МВД от 12.05.2026 № 290) |
| Приложить | Обычно сведения из ТД/паспорта/патента заполняются в форме; храните копии ТД и документов |

**Штрафы** за неуведомление / просрочку (ст. 18.15 КоАП): для Москвы — особо высокие (для организаций до порядка 1 млн ₽; для ИП — по санкциям статьи, уточнять актуальную редакцию КоАП перед подачей). Не рисковать сроком.

Аналогично — **уведомление о расторжении** в те же **3 рабочих дня**.

## 4. Миграционный учёт

- Постановку на учёт по месту пребывания обычно обеспечивает **принимающая сторона** (собственник жилья / гостиница / иное лицо), не всегда сам ИП-работодатель.
- Если работник проживает по адресу, связанному с работодателем, или ИП фактически принимает — уточнить обязанность по 109-ФЗ.
- Работодателю важно: у работника должна быть **действующая регистрация**; копию хранить в личном деле.
- При увольнении / смене адреса — контроль снятия/переучёта силами принимающей стороны.

## 5. Налоги и взносы (ИП-работодатель)

### НДФЛ

- ИП — налоговый агент: исчисляет и удерживает НДФЛ при выплате зарплаты.
- Для работающих по патенту с 2026 часто применяется **прогрессивная шкала 13–22%** (и для нерезидентов в этой категории — уточнять актуальную редакцию НК РФ у бухгалтера).
- **Уменьшение НДФЛ на фиксированные авансы по патенту** (ст. 227.1 НК РФ): работник пишет заявление + подтверждения оплаты; работодатель запрашивает **уведомление ФНС** о праве на уменьшение. Без уведомления ФНС уменьшать нельзя.

### Страховые взносы

- В общем случае — **как за обычного работника** (единый тариф страховых взносов; травматизм — по классу риска ОКЕД).
- Платежи / отчётность — по правилам 2026 (ЕНП / уведомления / РСВ) — вести через бухгалтера.

### Периодичность (типовая)

| Действие | Когда |
|----------|-------|
| НДФЛ удержание | При каждой выплате |
| Перечисление налогов/взносов | По срокам НК РФ (ежемесячно в составе ЕНП — уточнять календарь) |
| Отчётность по сотрудникам | ЕФС-1, РСВ, 6-НДФЛ — по календарю отчётности |
| Уведомление МВД | В течение 3 раб. дней (приём и увольнение) |

Точные КБК и даты — из ЛК ИП / сервиса бухгалтера на месяц приёма.

## 6. Зарплата только на карту/счёт

- Временно пребывающий иностранец без ВНЖ — **валютный нерезидент** (173-ФЗ).
- Выплата зарплаты наличными из кассы = незаконная валютная операция → **ст. 15.25 КоАП**.
- До подписания ТД получить реквизиты счёта и вписать в договор.
- В папке есть PDF банка «Солидарность» — сверить ФИО и реквизиты перед первой выплатой.

---

## 7. Увольнение через ~3 месяца

1. Заявление работника об увольнении по собственному желанию (за 2 недели, если нет соглашения о меньшей отработке) **или** соглашение о расторжении.
2. Приказ об увольнении, расчёт, выдача документов / ЭТК.
3. **Уведомление МВД о расторжении ТД** — ≤ 3 рабочих дней.
4. ЕФС-1 об увольнении — в срок по правилам СФР.
5. Проверить оплату патента на дату увольнения (на ответственность работника; работодателю важно не допускать работы без действующего патента).

Не оформлять «фиктивное» основание срочности задним числом.

## 8. Риски ИП и как снизить

| Риск | Как снизить |
|------|-------------|
| Просрочка уведомления МВД | Календарь + подача через Госуслуги в день подписания |
| Работа не по профессии/региону патента | Сверка патента с должностью и адресом работы |
| Зарплата ниже МЗП Москвы | Оклад ≥ **39 730 ₽** (полный месяц) |
| Наличные | Только безнал на счёт в РФ |
| Незаконный срочный ТД | Бессрочный + ст. 80 / ст. 78 |
| «Короткий» найм и внимание налоговой | Реальная трудовая функция, полный пакет, белая зарплата, взносы; не маскировать ГПХ под труд |
| Просроченный патент | Ежемесячный контроль квитанций |
| Нет ДМС | Не допускать к работе без полиса/договора медуслуг |
| ПДн | Не хранить лишние копии; не публиковать паспортные данные |

## 9. Пошаговый план «на этой неделе»

1. Заполнить реквизиты ИП и работника в `Трудовой_договор_иностранец_Узбекистан.docx`.
2. Получить СНИЛС/ИНН (файл-заготовка пуст), актуальные квитанции патента, реквизиты карты.
3. Подписать ТД (бессрочный), издать приказ.
4. В тот же / следующий день — ЕФС-1; в ≤ 3 раб. дня — уведомление МВД.
5. Настроить зарплатный проект / платёжку на счёт работника.
6. Передать бухгалтеру пакет для НДФЛ/взносов и (при желании) заявление на зачёт патентных авансов.
