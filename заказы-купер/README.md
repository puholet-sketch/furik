# Заказы Купера → перевыставление Фурику

Деньги списываются с бизнес-счёта ИП. В реестр для перевыставления Фурику попадают только согласованные позиции.

## Фильтр

**Включать:** зубные пасты, аджики, кетчупы, соусы, освежители воздуха, средства для стирки/гель, леденцы/конфеты Halls (+ иное по указанию).

**Не включать (кофейня):** апельсины, грейпфрут, лайм, лимоны, салфетки, вода, мята, перчатки, тоники Rich и прочий товар точки; сборку/доставку/сервисный сбор — пока не сказано иное.

**Пример исключения:** METRO 08.06.2026 — всё в кофейню (`скриншоты/2026-06-08_metro_кофейня-не-учитывать.png`).
